# ArbiAgent — Landing Page

AI-powered multi-protocol yield allocation infrastructure built on Arbitrum.

This repository contains the static landing page for ArbiAgent, built with HTML, CSS, and a minimal JavaScript file. No build step is required.

Run Locally

Start a local HTTP server from the project directory:

python3 -m http.server 8080

Then open:

http://localhost:8080

Deployment

The landing page is ready to be deployed on Vercel.

Production app:

https://arbi-agent-vault.vercel.app/
